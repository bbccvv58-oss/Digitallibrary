ការភ្ជាប់សំឡេង (연음)

២.៨ តើ 연음 ជាអ្វី?

연음 មានន័យថា ការភ្ជាប់សំឡេងពីព្យាង្គមួយទៅព្យាង្គបន្ទាប់។ នៅពេលព្យញ្ជនៈចុង 받침
ស្ថិតនៅមុខព្យាង្គដែលចាប់ផ្ដើមដោយ ㅇ និងស្រៈ
ព្យញ្ជនៈចុងនោះជាទូទៅនឹងភ្ជាប់ទៅជាផ្នែកដើមនៃព្យាង្គបន្ទាប់។

រូបមន្ត៖ CVC + V → CV + CV

ឧទាហរណ៍៖

១. 집에 → [지베] (ji-be) - 집 = ផ្ទះ - 에 = នៅ / ទៅកាន់ - 집에 = នៅផ្ទះ

២. 밥을 → [바블] - 밥 = បាយ - 을 = បច្ច័យកម្មបទ ប្រើក្រោយនាមដែលមាន 받침 -
밥을 = បាយ (ជាកម្មបទ)

ប្រយោគ៖ 저는 밥을 먹어요. ការបកប្រែ៖ ខ្ញុំញ៉ាំបាយ។ ការបំបែក៖ - 저 = ខ្ញុំ (គួរសម) -
는 = បច្ច័យប្រធានបទ - 밥 = បាយ - 을 = បច្ច័យកម្មបទ - 먹어요 = ញ៉ាំ

៣. 한국어 → [한구거] - 한국 = ប្រទេសកូរ៉េ - 어 = ផ្នែកស្រៈ ㅓ ដែលមាន ㅇ
នៅដើម - 한국어 = ភាសាកូរ៉េ

៤. 음악을 → [으마글] - 음악 = តន្ត្រី - 을 = បច្ច័យកម្មបទ - 음악을 = តន្ត្រី
(ជាកម្មបទ)

ប្រយោគ៖ 저는 음악을 들어요. ការបកប្រែ៖ ខ្ញុំស្ដាប់តន្ត្រី។ ការបំបែក៖ - 저 = ខ្ញុំ
(គួរសម) - 는 = បច្ច័យប្រធានបទ - 음악 = តន្ត្រី - 을 = បច្ច័យកម្មបទ - 들어요 = ស្ដាប់

ឧទាហរណ៍បន្ថែម៖ - 옷이 → [오시] = សម្លៀកបំពាក់ + បច្ច័យប្រធាន - 꽃이 → [꼬치] =
ផ្កា + បច្ច័យប្រធាន - 낮에 → [나제] = នៅពេលថ្ងៃ - 문을 → [무늘] = ទ្វារ +
បច្ច័យកម្មបទ - 책을 → [채글] = សៀវភៅ + បច្ច័យកម្មបទ - 밥이 → [바비] = បាយ +
បច្ច័យប្រធាន

ចំណាំ៖ ការភ្ជាប់សំឡេងមិនមានន័យថាប្ដូរអក្ខរាវិរុទ្ធទេ។ ត្រូវរក្សាការសរសេរដើម
ប៉ុន្តែបញ្ចេញសំឡេងតាមច្បាប់។

២.៨.២ ការភ្ជាប់សំឡេងព្យញ្ជនៈចុងទ្វេ

នៅពេលព្យញ្ជនៈចុងទ្វេ 겹받침 តាមពីក្រោយដោយព្យាង្គដែលចាប់ផ្ដើមដោយ ㅇ
សំឡេងមួយអាចនៅចុងព្យាង្គមុន ហើយសំឡេងមួយទៀតអាចភ្ជាប់ទៅព្យាង្គបន្ទាប់។

ឧទាហរណ៍៖ - 읽어요 → [일거요] - 읽다 = អាន - 어요 = ចុងកិរិយាសព្ទគួរសម - 읽어요
= អាន - 앉아요 → [안자요] - 앉다 = អង្គុយ - 아요 = ចុងកិរិយាសព្ទបច្ចុប្បន្នកាល -
앉아요 = អង្គុយ - 없어요 → [업써요] - 없다 = គ្មាន - 어요 = ចុងកិរិយាសព្ទគួរសម -
없어요 = គ្មាន

ចំណាំ៖ 없어요 មានការប្រែសំឡេងបន្ថែមទៅជាសំឡេងតឹងផងដែរ។

ការប្រែសំឡេងតាមច្រមុះ (비음화)

២.១០ តើ 비음화 ជាអ្វី?

비음화 មានន័យថា ការប្រែសំឡេងព្យញ្ជនៈទៅជាសំឡេងច្រមុះ។ សំឡេងច្រមុះក្នុងភាសាកូរ៉េមាន ៣
ប្រភេទ៖ - ㄴ = [n] - ㅁ = [m] - ㅇ = [ŋ]

នៅពេលព្យញ្ជនៈចុងមួយចំនួននៅមុខ ㄴ ឬ ㅁ សំឡេងរបស់វាអាចប្រែទៅជាសំឡេងច្រមុះ។

២.១១ ច្បាប់ទី១៖ ㄱ ក្លាយជា ㅇ

រូបមន្ត៖ ㄱ + ㄴ → ㅇ + ㄴ ㄱ + ㅁ → ㅇ + ㅁ

ឧទាហរណ៍៖ - 국물 → [궁물] = ទឹកស៊ុប - 막내 → [망내] = កូនពៅ - 작년 → [장년] =
ឆ្នាំមុន - 학년 → [항년] = ថ្នាក់រៀន / ឆ្នាំសិក្សា

ការបំបែក 국물៖ - 국 = ស៊ុប - 물 = ទឹក - 국물 = ទឹកស៊ុប ㄱ នៅចុង 국 ប្រែទៅជាសំឡេង
ㅇ ព្រោះវានៅមុខ ㅁ នៃ 물។

២.១២ ច្បាប់ទី២៖ សំឡេង 받침 [ㄷ] ក្លាយជា ㄴ

រូបមន្ត៖ ㄷ + ㄴ → ㄴ + ㄴ ㄷ + ㅁ → ㄴ + ㅁ

ឧទាហរណ៍៖ - 받는 → [반는] = ដែលទទួល / កំពុងទទួល - 믿는 → [민는] = ជឿ - 있는 →
[인는] = មាន / នៅ - 닫는 → [단는] = កំពុងបិទ

ការបំបែក 받는៖ - 받다 = ទទួល - 는 = ទម្រង់កំណត់នាម / សកម្មភាព - 받는 = ដែលទទួល /
កំពុងទទួល

ចំណាំ៖ ច្បាប់នេះអនុវត្តលើសំឡេង 받침 [ㄷ] មិនមែនតែលើអក្សរ ㄷ ដែលសរសេរត្រង់ៗប៉ុណ្ណោះទេ។

២.១៣ ច្បាប់ទី៣៖ ㅂ ក្លាយជា ㅁ

រូបមន្ត៖ ㅂ + ㄴ → ㅁ + ㄴ ㅂ + ㅁ → ㅁ + ㅁ

ឧទាហរណ៍៖ - 입니다 → [임니다] = គឺជា (ទម្រង់គួរសមផ្លូវការ) - 합니다 → [함니다] =
ធ្វើ - 앞문 → [암문] = ទ្វារខាងមុខ - 십만 → [심만] = មួយសែន

ប្រយោគ៖ 저는 학생입니다. ការបកប្រែ៖ ខ្ញុំជាសិស្ស។ ការបំបែក៖ - 저 = ខ្ញុំ (គួរសម) -
는 = បច្ច័យប្រធានបទ - 학생 = សិស្ស - 입니다 = គឺជា (ទម្រង់ផ្លូវការ)

២.១៤ ច្បាប់ទី៤៖ ㄹ និង ㄴ

នៅពេល ㄹ និង ㄴ ជួបគ្នាក្នុងលក្ខខណ្ឌសូរសព្ទជាក់លាក់ សំឡេងអាចប្រែទៅជាសំឡេង ㄹ ជាប់គ្នា
[ll]។ ឧទាហរណ៍៖ - 설날 → [설랄] = បុណ្យចូលឆ្នាំតាមចន្ទគតិកូរ៉េ - 신라 → [실라] =
នគរស៊ីឡា - 칼날 → [칼랄] = មុខដាវ

ការរឹងសំឡេង (경음화)

២.១៥ តើ 경음화 ជាអ្វី?
경음화 គឺជាបាតុភូតដែលព្យញ្ជនៈធម្មតានៅដើមព្យាង្គបន្ទាប់ប្រែទៅជាព្យញ្ជនៈតឹង។
ការប្រែសំឡេងសំខាន់ៗ៖ - ㄱ → ㄲ - ㄷ → ㄸ - ㅂ → ㅃ - ㅅ → ㅆ - ㅈ → ㅉ

២.១៦ ច្បាប់ទី១៖ ព្យញ្ជនៈចុងបង្កឱ្យសំឡេងបន្ទាប់តឹង
នៅពេលព្យញ្ជនៈចុងមានសំឡេងចុងមួយក្នុងក្រុម [ㄱ], [ㄷ], [ㅂ] ហើយតាមពីក្រោយដោយ ㄱ, ㄷ,
ㅂ, ㅅ ឬ ㅈ សំឡេងដើមអាចប្រែជាសំឡេងតឹង។
ឧទាហរណ៍៖ - 학교 → [학꾜] = សាលារៀន - 국밥 → [국빱] = បាយជាមួយស៊ុប - 책상 →
[책쌍] = តុសិក្សា - 옷고름 → [옫꼬름] = ខ្សែចងអាវ - 입구 → [입꾸] = ច្រកចូល
ការបំបែក 학교៖ - 학 = ធាតុផ្សំពាក្យទាក់ទងនឹងការសិក្សា - 교 =
ធាតុផ្សំពាក្យទាក់ទងនឹងសាលា - 학교 = សាលារៀន

២.១៧ ច្បាប់ទី២៖ កិរិយាសព្ទ និងគុណនាមមួយចំនួន
កិរិយាសព្ទ និងគុណនាមដែលមានព្យញ្ជនៈចុង ㄴ ឬ ㅁ អាចបង្កឱ្យព្យញ្ជនៈដើម ㄱ, ㄷ, ㅅ, ㅈ
នៃចុងកិរិយាសព្ទប្រែជាសំឡេងតឹង ក្នុងលក្ខខណ្ឌជាក់លាក់។
ឧទាហរណ៍៖ - 신다 → [신따] = ពាក់ស្បែកជើង - 앉다 → [안따] = អង្គុយ - 젊다 →
[점따] = ក្មេង / វ័យក្មេង - 삼고 → [삼꼬] = យកធ្វើជា / ចាត់ទុកជា
ប្រយោគ៖ 여기에 앉으세요. ការបកប្រែ៖ សូមអង្គុយនៅទីនេះ។ ការបំបែក៖ - 여기 = ទីនេះ -
에 = នៅ - 앉다 = អង្គុយ - 으세요 = ចុងកិរិយាសព្ទបែបសំណើគួរសម - 앉으세요 = សូមអង្គុយ

២.១៨ ការរឹងសំឡេងនៅក្នុងពាក្យផ្សំ
ឧទាហរណ៍៖ - 손등 → [손뜽] = ខ្នងដៃ - 발바닥 → [발빠닥] = បាតជើង - 길가 →
[길까] = ក្បែរផ្លូវ - 문고리 → [문꼬리] = ដៃទាញទ្វារ

២.១៩ តួនាទីរបស់អក្សរ ㅎ
នៅពេល ㅎ ស្ថិតនៅជាប់ព្យញ្ជនៈមួយចំនួន វាអាចធ្វើឱ្យព្យញ្ជនៈនោះក្លាយជាសំឡេងខ្យល់ខ្លាំង។
ក្នុងករណីខ្លះ ㅎ អាចបាត់សំឡេង។

២.២០ ច្បាប់ទី១៖ ㅎ + ㄱ = ㅋ
ឧទាហរណ៍៖ - 좋고 → [조코] = ល្អ ហើយ… - 축하하다 → [추카하다] = អបអរសាទរ -
놓고 → [노코] = ដាក់ចុះ ហើយ…
ការបំបែក 좋고៖ - 좋다 = ល្អ - 고 = បច្ច័យភ្ជាប់ មានន័យថា ហើយ / និង - 좋고 = ល្អ
ហើយ…

២.២១ ច្បាប់ទី២៖ ㅎ + ㄷ = ㅌ
ឧទាហរណ៍៖ - 좋다 → [조타] = ល្អ - 많다 → [만타] = ច្រើន - 싫다 → [실타] =
មិនចូលចិត្ត
ការបំបែក 많다៖ - 많 = ច្រើន - 다 = ចុងកិរិយាសព្ទទម្រង់វចនានុក្រម - 많다 = មានច្រើន

២.២២ ច្បាប់ទី៣៖ ㅎ + ㅈ = ㅊ
ឧទាហរណ៍៖ - 좋지 → [조치] = ល្អ មែនទេ / ល្អណាស់ - 그렇지 → [그러치] = មែនហើយ

២.២៣ ការបាត់សំឡេង ㅎ (ㅎ 탈락)
ឧទាហរណ៍៖ - 좋아요 → [조아요] = ល្អ - 놓아요 → [노아요] = ដាក់ចុះ - 많아요 →

ឆ្ងាញ់

ការប្រែសំឡេង ㄴ និង ㄹ (유음화)
២.២៤ តើ 유음화 ជាអ្វី?
유음화 គឺជាបាតុភូតដែលសំឡេង ㄴ និង ㄹ ប្រែទៅជាសំឡេង ㄹ ជាប់គ្នា [ll]
នៅពេលស្ថិតនៅជិតគ្នាក្នុងលក្ខខណ្ឌជាក់លាក់។

២.២៥ ច្បាប់ទី១៖ ㄴ + ㄹ = ㄹ + ㄹ
រូបមន្ត៖ ㄴ + ㄹ → ㄹ + ㄹ
ឧទាហរណ៍៖ - 신라 → [실라] = នគរស៊ីឡា - 천리 → [철리] = ចម្ងាយមួយពាន់លី - 난로 →
[날로] = ចង្ក្រាន - 진리 → [질리] = សេចក្ដីពិត

២.២៦ ច្បាប់ទី២៖ ㄹ + ㄴ = ㄹ + ㄹ
រូបមន្ត៖ ㄹ + ㄴ → ㄹ + ㄹ
ឧទាហរណ៍៖ - 설날 → [설랄] = បុណ្យចូលឆ្នាំកូរ៉េ - 물난리 → [물랄리] = គ្រោះទឹកជំនន់ -
칼날 → [칼랄] = មុខដាវ
ការបំបែក 설날៖ - 설 = ឈ្មោះបុណ្យចូលឆ្នាំតាមចន្ទគតិ - 날 = ថ្ងៃ - 설날 =
ថ្ងៃបុណ្យចូលឆ្នាំកូរ៉េ
២.២៧ ឧទាហរណ៍ក្នុងពាក្យផ្សំ

-   연락 → [열락] = ការទាក់ទង
-   편리 → [펼리] = ងាយស្រួល
-   권력 → [궐력] = អំណាច
-   난로 → [날로] = ចង្ក្រាន

ប្រយោគ៖ 나중에 연락할게요. ការបកប្រែ៖ ខ្ញុំនឹងទាក់ទងអ្នកនៅពេលក្រោយ។ ការបំបែក៖ -
나중 = ពេលក្រោយ - 에 = នៅ / នៅពេល - 연락하다 = ទាក់ទង - ㄹ게요 =
បច្ច័យបង្ហាញការសម្រេចចិត្ត ឬការសន្យារបស់អ្នកនិយាយ - 연락할게요 = នឹងទាក់ទង

ចំណាំ៖ 유음화 មិនអនុវត្តដោយស្វ័យប្រវត្តិលើការជួបគ្នារបស់ ㄴ និង ㄹ គ្រប់ករណីទាំងអស់ទេ។

ការបញ្ចូលសំឡេង ㄴ (ㄴ 첨가)

២.២៨ តើ ㄴ 첨가 ជាអ្វី?
ㄴ 첨가 មានន័យថា ការបន្ថែមសំឡេង ㄴ នៅពេលភ្ជាប់ពាក្យ ឬផ្នែកនៃពាក្យមួយចំនួន។
ជាទូទៅវាកើតឡើងនៅពេលព្យាង្គមុនមាន 받침 ហើយព្យាង្គបន្ទាប់ចាប់ផ្ដើមដោយស្រៈដែលសរសេរជា
이, 야, 여, 요 ឬ 유 ក្នុងលក្ខខណ្ឌដែលច្បាប់នេះអនុវត្ត។

២.២៩ ឧទាហរណ៍នៃ ㄴ 첨가
-   색연필 → [생년필] = ខ្មៅដៃពណ៌
-   꽃잎 → [꼰닙] = ស្រទាប់ផ្កា / ស្លឹកផ្កា
-   맨입 → [맨닙] = មាត់ទទេ / ដោយមិនមានអ្វីបរិភោគ
-   솜이불 → [솜니불] = ភួយកប្បាស
-   담요 → [담뇨] = ភួយ

ការបំបែក 색연필៖ - 색 = ពណ៌ - 연필 = ខ្មៅដៃ - 색연필 = ខ្មៅដៃពណ៌ - សំឡេងអាន៖
[생년필]
ការប្រែសំឡេង៖ ១. 색 មាន 받침 ㄱ។ ២. 연필 ចាប់ផ្ដើមដោយ ㅇ + ㅕ។ ៣. បន្ថែមសំឡេង
ㄴ តាមច្បាប់ ㄴ 첨가។ ៤. ㄱ នៅមុខ ㄴ ប្រែទៅជាសំឡេង ㅇ តាមច្បាប់ 비음화។ ៥.
លទ្ធផលគឺ [생년필]។
ការបំបែក 꽃잎៖ - 꽃 = ផ្កា - 잎 = ស្លឹក - 꽃잎 = ស្រទាប់ផ្កា / ស្លឹកផ្កា -
សំឡេងអាន៖ [꼰닙]
ការប្រៀបធៀបច្បាប់៖ - 연음 = ភ្ជាប់ព្យញ្ជនៈចុងទៅព្យាង្គបន្ទាប់ - ㄴ 첨가 = បន្ថែមសំឡេង
ㄴ - 비음화 = ប្រែព្យញ្ជនៈទៅជាសំឡេងច្រមុះ - 유음화 = ប្រែសំឡេង ㄴ និង ㄹ ទៅជាសំឡេង
ㄹ ជាប់គ្នា
ច្បាប់ទាំងនេះអាចកើតឡើងបន្តបន្ទាប់ក្នុងពាក្យតែមួយ។

ការប្រែសំឡេងទៅជាសំឡេងក្រអូមមាត់ (구개음화)

២.៣០ តើ 구개음화 ជាអ្វី?
구개음화 គឺជាបាតុភូតដែលព្យញ្ជនៈចុង ㄷ ឬ ㅌ ប្រែទៅជាសំឡេង ㅈ ឬ ㅊ
នៅពេលភ្ជាប់ជាមួយស្រៈ 이 ក្នុងលក្ខខណ្ឌសូរសព្ទជាក់លាក់។
រូបមន្ត៖ ㄷ + 이 → 지 ㅌ + 이 → 치

២.៣១ ច្បាប់ទី១៖ ㄷ ប្រែទៅជា ㅈ
ឧទាហរណ៍៖ - 같이 → [가치] = ជាមួយគ្នា - 굳이 → [구지] = ចាំបាច់ដល់ថ្នាក់នោះ /
ដោយចេតនា - 맏이 → [마지] = កូនច្បង

២.៣២ ច្បាប់ទី២៖ ㅌ ប្រែទៅជា ㅊ
ឧទាហរណ៍៖ - 밭이 → [바치] = ចម្ការ + បច្ច័យប្រធាន - 끝이 → [끄치] = ចុង /
ទីបញ្ចប់ + បច្ច័យប្រធាន - 해돋이 → [해도지] = ការរះឡើងនៃព្រះអាទិត្យ
ការបំបែក 해돋이៖ - 해 = ព្រះអាទិត្យ - 돋다 = រះ / លេចឡើង - 이 =
ធាតុបង្កើតនាម - 해돋이 = ការរះឡើងនៃព្រះអាទិត្យ

២.៣៣ ចំណុចត្រូវប្រយ័ត្ន
មិនមែនរាល់ពាក្យដែលមាន ㄷ ឬ ㅌ នៅមុខអក្សរ 이 សុទ្ធតែប្រែសំឡេងតាមច្បាប់នេះទេ។
ច្បាប់នេះអនុវត្តនៅពេល ㄷ ឬ ㅌ ស្ថិតនៅទីតាំង 받침 ហើយភ្ជាប់ជាមួយ 이 ដែលជាផ្នែកនៃបច្ច័យ
ឬធាតុបង្កើតពាក្យតាមលក្ខខណ្ឌស្តង់ដារ។

ច្បាប់សំឡេងផ្សេងៗដែលគួរស្គាល់

២.៣៤ ការបញ្ចេញសំឡេងរបស់ 의
ស្រៈ 의 មានលក្ខណៈពិសេស ព្រោះសំឡេងអានអាចប្រែប្រួលតាមទីតាំង និងតួនាទីវេយ្យាករណ៍។
ឧទាហរណ៍៖ - 의사 → [의사] = វេជ្ជបណ្ឌិត - 의자 → [의자] = កៅអី - 희망 → [히망]
= ក្ដីសង្ឃឹម - 민주주의 → [민주주의] ឬ [민주주이] = ប្រជាធិបតេយ្យ
គោលការណ៍៖ ១. 의 នៅដើមពាក្យ ជាទូទៅអានជា [의]។ ២. 의 នៅក្នុងព្យាង្គមិនមែនដើមពាក្យ
អាចអានជា [이]។ ៣. 의 ដែលប្រើជាបច្ច័យបង្ហាញភាពជាម្ចាស់ អាចអានជា [의] ឬ [에]។
ឧទាហរណ៍៖ 나의 책 ការបកប្រែ៖ សៀវភៅរបស់ខ្ញុំ។ ការបំបែក៖ - 나 = ខ្ញុំ - 의 = របស់
(បច្ច័យកម្មសិទ្ធិ) - 책 = សៀវភៅ

២.៣៥ ការបញ្ចេញសំឡេង ㅖ

២.៣៦ ការបញ្ចេញសំឡេង ㅐ និង ㅔ

ស្រៈទាំងពីរនេះមានសំឡេងជិតគ្នាខ្លាំងនៅក្នុងភាសាកូរ៉េសម័យបច្ចុប្បន្ន។ - ㅐ (ae): 개 = ឆ្កែ -
ㅔ (e): 게 = ក្តាម

គួរចងចាំអក្ខរាវិរុទ្ធ និងវាក្យសព្ទជាចម្បង
ព្រោះការបញ្ចេញសំឡេងរបស់អ្នកនិយាយជាច្រើនមានភាពស្រដៀងគ្នាខ្លាំង។

ចំណាំអំពីការរៀបចំសៀវភៅ៖ ឯកសារនេះប្រមូលផ្ដុំមេរៀនទី៤ ដល់ទី១៤ នៃជំពូកទី២
ដែលបានរៀបរាប់ក្នុងការសន្ទនានេះ។ សម្រាប់ការបោះពុម្ព ឬការសិក្សាផ្លូវការ
គួរផ្ទៀងផ្ទាត់ការបញ្ចេញសំឡេង និងពាក្យពន្យល់ជាមួយវចនានុក្រម និងឯកសារសូរសព្ទកូរ៉េស្តង់ដារ។
